# АвтоЖурнал PWA

Полностью офлайн-сервисная книжка автомобиля, рассчитанная в первую очередь на iPhone и публикацию на GitHub Pages.

## Возможности

- несколько автомобилей;
- сервисная история: дата, пробег, вид работы, стоимость запчастей/работ, заметки, фото;
- узлы и расходники с **двумя независимыми циклами**:
  - срок службы / замены в км и/или месяцах;
  - периодическая проверка в км и/или месяцах;
- раннее предупреждение отдельно в км и днях;
- отметка «Проверено» переносит только следующую проверку;
- отметка «Заменено» начинает заново срок службы и цикл проверок;
- журнал пробега и расчёт среднего километража в день;
- учёт расходов, категории, стоимость километра;
- аналитика за 6 месяцев, категории расходов, повторяющиеся ремонты, самые дорогие позиции;
- документы с файлами и сроком действия;
- центр напоминаний;
- экспорт напоминаний в `.ics` для системного Календаря iPhone;
- резервная копия / восстановление JSON;
- светлая / тёмная / системная тема;
- service worker и app shell для работы без интернета;
- все пользовательские данные хранятся только в IndexedDB текущего браузера/устройства.

## Публикация на GitHub Pages

1. Создайте публичный или приватный репозиторий GitHub.
2. Загрузите **содержимое этой папки в корень репозитория**.
3. Откройте `Settings → Pages`.
4. В `Build and deployment` выберите `Deploy from a branch`.
5. Выберите ветку `main` и папку `/ (root)`.
6. Откройте выданный GitHub Pages URL один раз в Safari.
7. На iPhone: `Поделиться → На экран «Домой»`.

После первого успешного открытия service worker кэширует оболочку приложения, и она запускается без сети.

## Проверка мобильного интерфейса

Требуется Node.js 20 или новее:

```sh
npm ci
npx playwright install chromium webkit
npm test
```

Проверки запускаются в Chromium и WebKit с мобильными размерами экрана: 320, 390 и 430 px, а также в альбомной ориентации. Они покрывают положение навигации, непрозрачность шапки, ширину дат, добавление и редактирование автомобилей, сохранение остальных форм, ошибки хранилища, повторное нажатие и офлайн-запуск. Safe-area отдельно моделируется через Chromium. Эмуляция не заменяет проверку Safari и установленной PWA на физическом iPhone.

Для проверки опубликованной версии задайте `BASE_URL=https://vzloman546-design.github.io/autojournal-pwa/`. Все данные тестов создаются в отдельных временных профилях браузера.

Офлайн-эмуляция в этом наборе выполняется в Chromium: в Playwright 1.63.0 у WebKit есть [известная ошибка офлайн-навигации через service worker](https://github.com/microsoft/playwright/issues/42775). Эта проверка в WebKit явно пропускается.

### Верхняя и нижняя границы PWA на iOS 27

Прозрачный режим `apple-mobile-web-app-status-bar-style=black-translucent` убран. Строкой состояния управляет iOS; шапка остаётся непрозрачной и закреплена через `position: sticky; top: 0`. WebKit использует такой верхний элемент для окраски системной области и подавления системного размытия. Нижняя навигация и фон корневой страницы используют один непрозрачный цвет, включая тёмную тему.

Основание: [разбор с проверкой на iOS 27](https://zenn.dev/uakihir0/articles/260920-ios27-pwa-blur) и [механизм цветовых расширений в WebKit](https://github.com/WebKit/WebKit/blob/main/Source/WebKit/UIProcess/API/Cocoa/WKWebView.mm). Тесты проверяют границы, цвета и поведение при прокрутке с уменьшенной высотой окна установленной PWA. Сам системный эффект iOS в настольной эмуляции отсутствует; окончательную визуальную проверку нужно выполнять на iPhone.

## Важное ограничение iOS

Статический PWA без push-сервера не может надёжно запускать произвольные фоновые задачи, когда приложение полностью закрыто. Поэтому напоминания всегда видны внутри приложения; для настоящих системных уведомлений в конкретную дату предусмотрен экспорт `.ics` в Календарь iPhone. Тестовое web-уведомление можно вызвать из раздела «Ещё» на поддерживаемых версиях iOS/режимах PWA.

## Данные и резервные копии

Удаление сайта из данных Safari, очистка данных браузера или удаление web-приложения может удалить IndexedDB. Регулярно делайте JSON-резервную копию из раздела `Ещё → Резервная копия`.
