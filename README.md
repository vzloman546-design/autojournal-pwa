# АвтоЖурнал

Локальная PWA-сервисная книжка автомобиля для iPhone и мобильных браузеров. Приложение работает без аккаунта и хранит пользовательские данные в IndexedDB на устройстве.

## Возможности

- несколько автомобилей с раздельными данными;
- история обслуживания и ремонта;
- сервисные записи без обязательного пробега;
- стоимость деталей и работ с автоматическим связанным расходом;
- заправки с live-расчётом любого третьего значения из суммы, объёма и цены за литр;
- контроль узлов: срок службы и график проверки работают независимо;
- действия «Проверено» и «Заменено» с корректным сбросом циклов;
- документы с файлами, сроком действия и напоминанием;
- статистика по пробегу, расходам и заправкам за выбранный период;
- уведомления о проверках, заменах, документах, актуальности пробега и резервной копии;
- экспорт напоминаний в ICS;
- резервная копия и восстановление JSON;
- офлайн-работа после первого запуска через Service Worker;
- светлая, тёмная и системная темы;
- iPhone safe-area, полноэкранные вторичные разделы, swipe-back и swipe-down для bottom sheet.

AI-ассистент, распознавание чеков и страницы поддержки/инструкции в проект не входят.

## Структура

- `index.html` — точка входа;
- `app.js` — интерфейс и бизнес-логика;
- `styles.css` — весь production UI;
- `db.js` — IndexedDB;
- `sw.js` — офлайн-кэш PWA;
- `manifest.webmanifest` и `icons/` — установка на главный экран;
- `tests/app.spec.cjs` — регрессионные мобильные тесты Chromium/WebKit.

## Проверка

```bash
npm ci
npx playwright install chromium webkit
npm test
```

GitHub Actions автоматически запускает тот же набор тестов при изменении production-кода.
